# FoodBridge – From Surplus to Smiles

FoodBridge connects food donors (restaurants, caterers, marriage halls, hostels and canteens) with food receivers (NGOs, shelters and community kitchens), with volunteers handling pickup and delivery, so surplus edible food is rescued before it spoils.

## Quick start

```bash
npm install
npm run seed
npm run dev
```

## Workspace layout

- `apps/web` – frontend web application
- `apps/api` – backend API server
- `packages/shared` – shared types and constants used by the apps

## Demo accounts

All seed users are synthetic and use `example.test` email addresses. The shared demo password for seed users only is `FoodBridge2026!`.

## Disclaimer

- FoodBridge does not certify or verify food safety. Safety information is entered by the donor and is not independently verified.
- Impact figures are estimates based on stated assumptions.
- FoodBridge does not claim any tax or legal benefits.
- All data is synthetic.
